Трекер тренировок — офлайн-версия (PWA)

Файлы: index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png.
Нужно загрузить ВСЕ файлы в одну папку на HTTPS-хостинг (GitHub Pages, Netlify и т. п.).

Установка на iPhone:
1. Откройте адрес сайта в Safari (при включённом интернете) и дождитесь загрузки.
2. Подождите несколько секунд, чтобы приложение закэшировалось.
3. Поделиться -> На экран «Домой» -> Добавить.
После этого иконка открывается без интернета.

Обновление: при изменении файлов поменяйте VERSION в sw.js (например wt-v2).
Данные хранятся на телефоне; делайте резервную копию через «Ещё» -> «Копировать».
